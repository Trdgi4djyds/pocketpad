# PocketPad

Manette portable pour jeux PC : application Android + logiciel PC Windows (PocketPad Hub).
Connexions : câble USB (ADB), Wi-Fi, Internet (PIN) et Bluetooth HID.

## Dépôt GitHub

- Dépôt public : https://github.com/Trdgi4djyds/pocketpad
- Téléchargements : https://github.com/Trdgi4djyds/pocketpad/releases/latest

## Accès GitHub

Ne jamais écrire de token GitHub dans le code source.
Le token se configure comme variable d'environnement (`GITHUB_TOKEN`), en dehors du dépôt.
